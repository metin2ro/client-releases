# Metin2RO — clientul de joc

Aici se vor publica **versiunile oficiale ale clientului Metin2RO**, cu sumele de control și semnăturile lor.

> **Încă nu există nicio versiune publică.** Lansarea se anunță aici și pe Discord.
> Orice „client Metin2RO” găsit în altă parte **nu** e oficial.

## Ce va fi diferit la clientul nostru

- **Conexiune autentificată.** Clientul verifică identitatea serverului înainte să trimită parola, iar fiecare pachet e criptat și protejat la modificare.
- **Fișiere semnate.** Clientul verifică fișierele jocului după un manifest semnat și refuză orice fișier modificat.
- **Fără drepturi de administrator.** O eventuală problemă în client nu îți poate compromite calculatorul.
- **Doar în limba română.**
- Platforme: Windows 10/11, Linux prin Wine/Proton, Android experimental (Winlator).
